# 扩大开发集后的学习曲线

本报告只汇总已完成的固定实验，没有训练新模型、修改标签或从多个抽样种子中挑选最好结果。证据来自 `outputs/application_factorial/20260927_v1/summary.json`；全部数值、三个种子、各来源与实际训练计数保存在同目录的 `learning_curve_summary.json`。

整体上，增加开发数据让两种固定模型的概率误差下降、排序能力上升：三个预先指定的抽样种子都出现这一趋势。不过，部分来源的表现会倒退；这不是“数据越多，每批歌都一定更好”的证据。

## 比较的含义

这次使用的 1,915 首／908 位艺人全部已经是开发数据。每首歌的结果来自未用该艺人训练的外层模型，五个外层测试折使用同一批歌曲来比较全部训练规模。`dev1206`、`hist239`、`val266`、`fresh204` 仅保留历史来源名称；尤其 `fresh204` 已不是未来模型的全新验证集。

`baseline_original` 是原有训练配方和原判断规则；`new_original` 仅把 pop、ambient 换成固定的不加类别权重、C=0.0003 的分类头，并按协议使用对应的原概率判断规则。学习曲线没有优化阈值。Brier 和 log loss 越低越好，衡量概率误差；AP 越高越好，衡量排序表现。FP、FN 是“歌曲×标签”的误报、漏报次数，不是不同歌曲数。

40% 和 70% 指每一来源中选中的艺人比例，向上取整，并保留该艺人的所有歌曲。三个种子分别决定嵌套子集；100% 在三个种子下完全相同，每外层折仅拟合一次，不重复计为三次结果。概率指标的种子均值是三个完整外层汇总结果的算术平均，范围是这三个值的最小值与最大值，均不是置信区间。

两种配方的 pooled Brier、log loss、AP 在全部三个种子上都按 40%→70%→100% 单调改善。baseline 的 Brier 三种子均值为 0.130024→0.127875→0.126701；new 为 0.128388→0.125829→0.124377。相应 AP 为 0.589989→0.598484→0.604998，以及 0.596238→0.606934→0.615110。

概率改善不等于每个误报/漏报指标同时改善。baseline 的 FP 三种子均值为 1147.7→1161.7→1155，没有单调下降；new 的 FP 均值下降，但种子 nested-2 的 FN 在 40%→70% 时从 505 增到 522。全量的 new_original 也比 baseline_original 多 132 次误报（1287 对 1155），其 F1 更低。这说明单独更换分类头的概率改善，并不足以自动减少误报；本轮完整预算的判断规则比较见最后一节。

原开发来源 dev1206 的三个概率指标，在两个配方与所有种子中都单调改善。其余来源共有 20 个“规模增加但指标变差”的相邻比较，完整清单在 JSON 的 `nonmonotone_probability_transitions` 中。它们集中于以下情况：

- hist239：两个配方的 nested-0 在 70%→100% 时，Brier、log loss、AP 都变差。例如 baseline 的 AP 从 0.638778 降到 0.616820，new 从 0.636146 降到 0.621107；部分 40%→70% 的比较也退步。
- val266：两个配方的 nested-0 在 70%→100% 时，三个指标都变差；baseline 的 nested-2 的 AP 也略降。
- fresh204：baseline 的 nested-1 在 70%→100% 时，Brier 从 0.109642 增至 0.110365，AP 从 0.690301 降至 0.680866；new 在该来源的全部三个种子和三个指标上都单调改善。

这些比较共享测试歌曲，且训练子集嵌套、100% 终点相同。20 个退步记录不是 20 次独立实验，也不能用三个种子做常规独立样本显著性检验。

## 与本轮主要检验的关系

学习曲线是固定原规则的诊断，不用于重新挑选候选。预先指定的主要比较是 full 的 new_tuned 对 baseline_original：pop+ambient 误报 776→697，减少 10.1804%；总体 micro F1 0.605109→0.613212，macro Brier 0.126701→0.124377，全部预设开发门槛通过。通过幅度接近 10% 的误报门槛，且仍有漏报代价：全部标签 FN 530→540。

这只比较按各外层训练子集重新拟合的两种配方，没有比较已安装的应用与一个最终候选。所有来源都已有历史暴露，阈值和方法也受到过去结果启发；这不是新歌验收或统计显著性结论。本阶段没有拟合部署模型、获取新歌曲或替换应用。后续若推进，须先固定最终训练及决策方法，再用保守排除范围之外的新艺人，与真实已安装基线作单独确认。
