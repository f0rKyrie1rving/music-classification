# 我们到底在改进什么？

**这项研究主要想让模型报出的概率更可信。**

原来的音乐分类系统会听一段音乐，分别给电子、流行、氛围、摇滚打分。
例如，它可能说“这首歌带有摇滚标签的概率是 80%”。

这里有两个不同的问题：

| 问题 | 通俗理解 | 当前研究做到了哪一步 |
| --- | --- | --- |
| 能否识别音乐特征 | 能否把更像摇滚的歌排在前面 | 沿用已有模型 |
| 报出的概率是否靠谱 | 很多被报为 80% 的歌，是否大约 80% 带有摇滚标签 | 正在研究和验证 |

如果模型经常过于自信，就可以在它打分之后，加一道“校正概率”的步骤。
这像给一台总是报高的温度计校正读数。音乐标签有遗漏和争议，因此我们目前
核对的是数据源已有的标签，不把它当作音乐风格唯一正确的答案。

之前已经比较了原始概率、完整校准，以及“证据不足就少调一点”的谨慎校准。
现有旧数据支持一个取舍：谨慎校准避免了一些不必要的调整，也少获得了一些改善。

接下来的新歌曲验证相当于换一套考卷：**模型和调整规则先固定，再看新歌的结果。**
如果改善仍然存在，说明它在这批新歌曲上也有用；如果没改善，或证据不清楚，
也会保留结果，不用这套考卷反复改到满意为止。

当前这些校准变换不会改变同一个标签下歌曲的分数排序。概率变得更可信，
不自动等于识别准确率、排序能力或所有歌曲的判断都更好。一首歌可以同时带有
流行和摇滚标签，所以四个概率也不需要加起来等于 100%。

研究模型与应用里的最终模型是不同的训练版本。研究验证完成后，若要把方法
接入应用，还需要为应用模型准备合适的独立校准数据和验证流程。
