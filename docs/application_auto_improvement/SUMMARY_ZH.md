# 全自动改进：第一轮开发结果

2026-09-27。本轮已经完成，不需要人工试听。

**新办法减少了一些误报，但也漏掉了更多正确标签，整体分类表现略降。因此没有通过事先设定的标准，现有应用继续保留。**

## 用最直白的数字说明

在原有 1,206 首开发歌曲、469 位艺人的分组检查中：

| 流行与氛围两类合计 | 旧配方 | 自动选择的新配方 | 变化 |
| --- | ---: | ---: | --- |
| 误报：原标签没有，模型却报了 | 534 次 | 508 次 | 少 26 次，下降 **4.87%** |
| 漏报：原标签有，模型却没报 | 174 次 | 186 次 | 多 **12 次** |

这里按“歌曲 × 风格标签”计数，少 26 次误报不等于修好了 26 首歌。同一首歌可能涉及多个标签。来源标签作为统一参考，尚未人工确认其是否完整。

这轮说明：模型确实可以更少报错，但当前改法带来的收益还不足，不能直接宣布识别更好了。

## 这次具体改了什么？

以前主要调整模型报出的概率数字。这次实际尝试了两项变化：让分类器最后一层更保守，以及自动选择“多少分才贴上某个标签”的门槛。

只调整 pop（流行）和 ambient（氛围）；电子和摇滚保持相同配方作为对照。候选采用不加类别权重的逻辑回归，固定比较 C=0.0001、0.0003、0.001，保留旧配方作回退。C 越小，分类器受到的限制越强。

程序把开发歌曲按艺人分成五组。每次用四组开发、剩下一组检查；开发组内部再分四组，用于选择分类器和门槛。因此，本轮新增的选择不会接触对应检查组的答案。程序同时检查概率误差、误报和漏报，不能通过“几乎不报标签”来获得虚假的改善。

比较双方均是**在每个训练子集上重新训练的配方**，不是拿已在全部 1,206 首上训练过的应用直接考试。这些开发歌曲过去已用于选择旧模型、表征和门槛，因此本轮仍是开发证据，不能当作完全未见数据上的确认。

## 为什么判定未通过？

在运行之前，已固定要求：两类误报合计至少下降 10%；各类误报不增加；漏报增加受到限制；综合 F1 不降低；两项概率误差不变差。

| 检查项 | 结果 | 是否通过 |
| --- | --- | --- |
| 流行＋氛围误报至少减少 10% | 减少 4.87% | 否 |
| 两类各自误报不增加 | 流行少 11 次，氛围少 15 次 | 是 |
| 四类总体召回率最多下降 3 个百分点 | 68.3621% → 67.3276%，下降 1.0345 个百分点 | 是 |
| 单类召回率最多下降 5 个百分点 | 最大下降为氛围的 3.2787 个百分点 | 是 |
| 综合 F1 不下降 | 0.577988 → 0.577236 | 否 |
| 四类平均 Brier 误差不增加 | 0.132641 → 0.132068 | 是 |
| 四类平均 log loss 不增加 | 0.418099 → 0.415355 | 是 |
| 电子／摇滚结果完全相同、检查行完整 | 全部一致，1,206 行各检查一次 | 是 |

F1 同时考虑误报与漏报。这次下降很小，不能称为“显著变差”，但确实不满足提前规定的“不下降”。这些通过线是本轮选择的应用取舍，不是统计显著性检验。

Brier 误差相对下降约 **0.43%**，log loss 相对下降约 **0.66%**，表示对来源标签的概率分数有小幅改善；它们不是准确率提高。此次开发检查与此前 204 首新歌验收采用不同数据和训练方式，不能直接比较两个阶段的改善百分比。

## 分别看流行与氛围

| 标签 | 误报：旧 → 新 | 漏报：旧 → 新 | 召回率：旧 → 新 | F1：旧 → 新 | Brier：旧 → 新 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 流行 | 203 → 192 | 125 → 129 | 52.11% → 50.57% | 0.45333 → 0.45128 | 0.15015 → 0.15108 |
| 氛围 | 331 → 316 | 49 → 57 | 79.92% → 76.64% | 0.50649 → 0.50067 | 0.13861 → 0.13539 |

概率误差的收益主要来自氛围，流行的 Brier 反而略增。两类 F1 都略降，所以不能说“两个标签都变好了”。

五个外层组的误报均有小幅减少，但没有一组达到两类误报减少 10%。综合 F1 三组上升、两组下降，合并全部歌曲后仍略降。各组训练数据相互重叠，不能把“三组变好”解释成未来有 60% 的成功率，也不能只留下有利的组。

六个“标签 × 外层组”采用新分类头，其余四个保留旧头。其中三个选择触发保护条件，完整退回旧配方。流行在一组中的门槛记录仅存在浮点末位差异，实际判断没有变化，不计为有实质意义的调整。

## 本轮已经完成和保留的东西

- 全自动开发流程、固定规则、输入校验与按艺人分组记录。
- 所有内层预测、选择理由、226 个拟合分类头及五组外层结果。
- 22 项合成测试通过，包括把检查组答案翻转后，拟合和选择仍不改变的检查。
- 保存的全部内层／外层模型、预测、选择和汇总均已重放核对通过。
- 独立脚本另完成 2,077 项核验，重新计算指标与通过线，结论一致。
- 本轮没有生成全数据最终候选，没有替换应用，也没有获取新歌。没有自动填写听辨答案或修改来源标签。

按预先固定的规则，这个候选流程到此结束。当前证据不支持只靠这组分类头和门槛调整来发布新版；也不能据此认定所有自动改进方法都无效。

下一轮若继续研究，应另立问题与方案，例如检查增加训练素材或改进音频表征是否带来更大的收益。仍可采用全自动验证，不需要先完成试听；只有需要裁决具体歌曲的真实风格时，才需要额外听辨证据。
