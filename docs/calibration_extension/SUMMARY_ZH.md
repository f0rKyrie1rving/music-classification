# 三组补充实验：校准为什么有效，什么时候又没有帮助

本轮主实验已经完成：在同一批 1,206 首歌、469 位艺人上，比较 MAEST、MERT-v0、
MERT-v1 三版音频模型；每版分别采用“氛围音乐加权”和“全部不加权”两种设置，
每种设置重新划分、拟合 20 次，共 120 套拟合结果。每套比较 7 种概率处理方式。

**最重要的发现：先前校准的收益，一个重要来源是修正训练权重造成的概率偏移。
取消这项权重后，完整校准不再稳定有利。**

## 1. 为什么之前会变好？

原来的模型在训练时，会额外重视“氛围音乐”这个类别。这样会改变模型面对漏报和
误报时的取舍，但输出的数字也可能偏高。

这次只改变氛围音乐的训练权重，其他条件相同。20 次主实验的平均值如下：

| MAEST 的氛围音乐结果 | 数值 |
| --- | ---: |
| 评分歌曲中实际带有该标签的比例 | 20.66% |
| 使用训练权重时，模型给出的平均概率 | 36.11% |
| 不使用这项权重时，模型给出的平均概率 | 20.11% |

这不是说每首歌都应该预测成 20%，而是说明整批歌曲的概率被整体抬高了。
整体平均数接近真实比例，也不等于各个概率区间都已校准。

我们还比较了简单的权重偏移修正、只调整整体高低、以及完整校准：

| MAEST 氛围标签的处理方式 | 平均概率误差，越低越好 |
| --- | ---: |
| 加权训练，直接输出 | 0.17422 |
| 加权训练，加简单权重修正 | 0.14344 |
| 加权训练，只校正整体高低 | 0.14330 |
| 加权训练，完整校准 | 0.14235 |
| 不加权训练，直接输出 | 0.14108 |

这些对照支持：**类别权重造成的整体偏移，是本设置中校准收益的重要来源。**
不能据此说所有改善都由它造成，也不能给出“解释了百分之几”的因果结论。
如果目标更重视召回率或不同错误的代价，训练权重仍可能有其他用途。

这里的“简单权重修正”只用训练集的类别比例，不需要额外拟合校准器。它是已有
方法的对照，不能把它包装成新算法。

## 2. 换模型后还成立吗？

MAEST、MERT-v0 和 MERT-v1 都出现了同样的主要现象：

- 氛围音乐加权后，原始概率的误差比不加权更大，三版模型各 20 次都是如此。
- 简单的整体偏移修正，就能得到接近完整校准的氛围标签平均误差。
- 取消这项权重后，完整校准不再稳定改善四标签平均误差。

这是**同一套 Jamendo 歌曲上的跨模型比较**。MERT 的两版属于同一模型家族，
它们并不代表两个不同的数据来源；本轮也没有完成跨数据集验证。
三版模型使用固定的共同参数，结果不能当作“各模型调到最好之后”的性能排名。

## 3. 反复训练，结论稳定吗？

我们每次重新分配训练、校准和评分歌曲，并保证同一位艺人不会同时出现在这三组。
然后重新拟合标准化参数、分类头和校准器。音频大模型本体保持固定。

下表统计“完整校准比该设置的原始输出更好”的次数，评分是四个标签平均的 Brier 误差：

| 音频模型 | 氛围音乐加权时 | 全部不加权时 | 不加权后，完整校准的平均误差变化 |
| --- | ---: | ---: | ---: |
| MAEST | 20/20 | 4/20 | +0.001235，略差 |
| MERT-v0 | 20/20 | 11/20 | +0.000103，略差 |
| MERT-v1 | 20/20 | 11/20 | +0.000273，略差 |

两个 MERT 版本虽然有 11 次变好，但少数较大的恶化抵消了较小的改善，所以平均
仍略差。我们保留了所有结果，没有挑表现好的随机划分。

20 次反复使用了同一批歌，因此 **20/20 不代表未来必然成功，也不是 20 份独立数据的
证据**。这些数字描述的是当前数据和固定划分规则下的波动。

谨慎校准也有代价：去掉其中的“多留一点余地”规则、保留相同校准预测后，加权条件
下三版模型各有 17/20 次误差更低。不能声称原谨慎策略已经胜过其他办法。

## 补充样本与检查

之前的 266 首歌、200 位艺人用于另列的回顾性分析。它们与训练池艺人不重叠，但
之前已经看过 MAEST 的结果，因此不能重新叫作“全新测试集”。
两套 MERT 特征现已全部提取成功，并对 120 套已拟合模型完成评分，没有失败或替换歌曲。
这批歌上，加权设置的完整校准在三版模型中仍各改善 20/20 次；不加权设置下，
MAEST 仅改善 1/20 次，两个 MERT 版本各 9/20 次，三者的平均误差仍略有恶化。
这些补充结果与主实验的条件性结论一致，但不能当作新的独立确认。
全部回顾性数字见[详细报告](REPORT.md)。

本轮 16 项程序测试通过；独立验证器完成 456,414 项数值与文件检查，错误数为 0，
重建比较的最大绝对差为约 3.02×10⁻¹⁴。检查保存参数能否重建概率、数据是否错位、
评分与汇总是否正确，以及另三个未改变权重的标签是否保持完全相同。
两版 MERT 的旧音频控制特征都精确复现，最大差为 0。检查数量不代表统计证据强度。

## 对科研和应用意味着什么？

研究问题现在更清楚了：**“校准看起来有效，究竟是在修复什么？训练选择改变后，
它还值得做吗？”** 这比只报告误差降低了多少更有解释力。

类别权重与概率偏移的关系已经有[直接研究](https://arxiv.org/abs/2205.04613)，
音乐分类校准也有[已有论文](https://arxiv.org/abs/2206.13071)。我们的材料应定位为
音乐模型上的可复现实证与对照研究，不能声称发现了新的校准原理。
本轮补齐了三组实验，但尚未变成一篇已经适合录用的期刊论文。

实际应用还没有替换模型。本轮提示“取消类别权重”值得作为后续候选方案，
但改变权重可能同时改变识别、召回和误报表现；不能只凭概率误差较低就直接上线。

代码和复现入口见[研究说明](../../research/calibration_extension/README.md)。
这轮没有新增未知来源的数据需求；项目外的历史使用情况、预训练数据重叠和艺人
别名问题仍无法从现有记录确认，继续作为研究限制保留。
