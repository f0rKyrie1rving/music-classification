# 为什么有一组歌曲越校准越差？

已经检查完。**我们找到了具体的问题表现：校准器把摇滚的概率往下调、把流行音乐
的概率往上调，但在这批评估歌曲上，这两个方向都让平均概率离实际标签比例更远。**

## 用摇滚举例

用于学习“怎么校正”的参考歌曲中：

- 有摇滚标签的歌曲约占 **16.4%**。
- 原模型平均报 **21.9%**，整体报高了。
- 校准器因此学到了一种平均向下调整的规则。

可是，换到另一批用来检查效果的歌曲：

- 有摇滚标签的歌曲约占 **18.9%**。
- 原模型平均报 **18.1%**，在平均值上已经接近了。
- 套用刚才的校正规则后，平均降到了 **13.3%**，反而偏低了。

这就像依据一次偏难的练习题调整自己的信心，换了一份题目后仍然照搬同样的调整。
参考题和检查题并不完全一样，调整未必合适。

平均值只是说明问题的入口。我们同时核对了每首歌的概率误差，摇滚的 Brier
确实变差；不是仅凭几个平均数就认定全部概率都不准。

## 其他类别呢？

| 类别 | 评估歌曲的标签比例 | 原模型平均报多少 | 校准后平均报多少 |
| --- | ---: | ---: | ---: |
| 流行音乐 | 20.2% | 21.3% | 26.4% |
| 摇滚 | 18.9% | 18.1% | 13.3% |
| 氛围音乐 | 24.7% | 32.2% | 19.8% |

流行音乐被往偏高的方向调整。氛围音乐则从平均报高变成了平均报低，逐首歌算下来，
总体误差只改善了一点点，没有像另外四组那样提供足够的收益。

## 会不会只是一位艺人的歌曲影响太大？

我把这批评估歌曲中的 **94 位艺人逐一检查**：每次只在计算中暂时去掉一位，
其余都保持不变。结果是，**去掉任何一位，校准后的整体误差仍然比原来更高**。

这说明结果不是靠单独一位艺人就能扭转的。正式分析没有删除任何歌曲，
这个检查也不能证明所有艺人或所有未来歌曲都会出现相同情况。

## 这轮研究多弄清楚了什么？

上一轮发现“数据多一些，校准通常更稳定”。这一轮补充了：
**即便调整学得很稳定，如果它不适合另一批歌曲，仍然可能越调越差。**

目前观察到类别比例和模型分数行为都有差异。我们还不能证明究竟是哪一个因素
单独造成失败，也不能把它简单归结为“样本少”或“标签错了”。

接下来值得测试的是一种更谨慎的办法：**先在参考歌曲内部检查调整是否有用，
证据不足时少调一点，或者保留原来的概率。** 这还只是下一轮候选方法，尚未验证有效。
那一轮不能用评估歌曲来挑最好的调整幅度，否则就相当于拿答案来调方法。

本轮没有训练新模型，没有改动原项目，也不需要你提供新数据。
