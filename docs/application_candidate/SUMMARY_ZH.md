# 固定候选版本已训练完成

2026-09-27。候选 `music-candidate-20260927-v1` 已保存，可以独立运行，也可以和现有应用分析同一段音频。**本轮完成的是固定版本的训练与运行核验；还没有进行新歌验收，也没有替换现有应用。**

## 这个版本改了什么？

| 部分 | 固定候选采用的方式 | 默认判断门槛 |
| --- | --- | ---: |
| 流行 pop | 用全部 1,915 首开发歌曲重新训练 | 0.275 |
| 氛围 ambient | 用全部 1,915 首开发歌曲重新训练 | 0.20 |
| 电子 electronic | 直接保留现有应用的分类器 | 0.40 |
| 摇滚 rock | 直接保留现有应用的分类器 | 0.275 |

训练材料来自 908 位艺人。流行和氛围分类器采用上一轮确定的 C=0.0003、不加类别权重的逻辑回归；音频特征提取模型没有重新训练。电子和摇滚直接复制真实旧应用的参数，避免在本轮改变它们。

门槛由提前固定的四组内部检查程序计算：每次用其中三组训练、另一组提供打分，按完整艺人分组，再根据全部内部预测选择门槛。流行选中保留原规则，氛围选中 0.20；两项都满足内部选择约束，没有触发回退。这与上一轮各外层组的新分类器门槛选择一致，但这些检查仍使用已有开发数据。

选完门槛后，两类最终分类器各用全部 1,915 首重新拟合一次。全流程共进行 18 次分类头拟合：16 个只用于内部选择的辅助头，加 2 个最终头。最终候选只使用后两个新头和两个复制的旧头，不是把 18 个模型混合投票。

表中门槛为便于阅读的显示值；程序始终用文件中保存的完整精度值判断，不会拿四舍五入后的分数决定标签。新氛围头没有类别权重，因此不会再施加旧应用的氛围概率偏移。

## 已经检查了哪些事情？

- 18 项候选训练／推理测试全部通过，包括艺人隔离、完整预测覆盖、门槛重放、文件损坏拒绝，以及失败拟合禁止自动重试。
- 保存的内部预测与门槛选择精确重放，最终模型参数导出和重新加载一致。
- 在全部 1,915 个缓存向量上，电子／摇滚的完整精度分数、显示分数和标签均与真实旧应用完全相同；两种判断模式都检查过。
- `precision_target` 模式继续关闭流行／氛围标签，保留电子／摇滚门槛，因此其所选标签整体与旧应用相同。流行／氛围的显示分数仍会随新分类器改变。
- 独立脚本完成 **137,747 项核验**，包括 18 个模型的训练行、缩放参数、类别计数、概率偏移、拟合配置、保存参数、阈值选择和文件哈希，最大重算数值差约 1.11×10⁻¹⁶。
- 独立核验还检查了实际门槛附近的 13 个合成向量，电子／摇滚与旧应用保持精确一致。
- 一段已有本地 30 秒音频完成真实 CPU 特征提取和新旧推理，重新提取的 float32 特征与缓存最大差值为 **0**。这确认程序能运行，不代表这首歌的风格判断经过人工确认。
- 旧应用的模型文件、概率修正文件、版本和推理入口均未修改；没有获取新歌曲、填写试听答案、发布安装包或自动安装候选。
