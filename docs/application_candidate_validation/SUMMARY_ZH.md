# 固定候选版本的新歌确认

**结果：通过预先固定的确认规则（GO），独立复核通过。** 2026年9月28日，固定候选与现有v1.1应用完成了同一批372首歌曲、250位艺人的比较。歌曲获取和特征提取全部成功；这批歌曲及艺人没有进入本项目已记录的早期训练、调试和评估材料。

最直观的变化是：**流行、氛围标签合计少了28次误报，多了2次漏报。** 综合识别表现提高，概率误差也降低。这轮没有继续训练或调整门槛，现有应用尚未被替换。

| 默认模式的结果 | 现有v1.1应用 | 固定候选 | 变化 |
|---|---:|---:|---:|
| 流行、氛围合计误报 | 152次 | 124次 | 减少18.42% |
| 流行、氛围合计漏报 | 59次 | 61次 | 增加2次 |
| 全部四类误报 | 225次 | 197次 | 减少28次 |
| 全部四类漏报 | 111次 | 113次 | 增加2次 |
| 总体精确率 | 54.91% | 58.00% | 提高3.09个百分点 |
| 总体召回率 | 71.17% | 70.65% | 降低0.52个百分点 |
| 综合F1，越高越好 | 0.619910 | 0.637002 | 提高0.017093 |
| Brier概率误差，越低越好 | 0.128989 | 0.125475 | 相对降低2.72% |
| 对数损失，越低越好 | 0.405714 | 0.394837 | 相对降低2.68% |

误报、漏报按“歌曲×标签”计数。例如，一首歌同时被错误标成流行和氛围，算两次误报。因此“少了28次误报”不一定等于“少错了28首歌”。精确率表示报出的标签有多少与数据集标签一致；召回率表示数据集已有标签中有多少被识别出来。

电子、摇滚的全精度分数和两种模式的标签均完全一致。较保守的`precision_target`模式仍关闭流行、氛围输出，所有标签判断也完全一致：总体精确率82.05%、召回率33.25%、F1为0.473198；只有41.67%的歌曲收到至少一个标签。该模式是补充检查，正式判断使用默认`f1`模式。

**改善有多确定。** 把同一艺人的歌曲放在一起，成对重抽样2,000次；每一次都让两个版本面对相同的歌曲。下表均为“候选减现有应用”，误报及概率误差的差值低于0表示改善。

| 指标变化 | 实际差值 | 95%区间 |
|---|---:|---:|
| 流行、氛围误报的相对变化 | −18.42% | [−26.90%, −9.70%] |
| 每首歌的流行、氛围误报次数 | −0.075269 | [−0.115705, −0.037592] |
| 折算为372首的误报次数变化 | −28.00 | [−43.04, −13.98] |
| 总体Brier误差 | −0.003514 | [−0.005914, −0.001195] |
| 总体对数损失 | −0.010877 | [−0.018907, −0.003329] |
| 总体F1 | +0.017093 | [+0.002278, +0.033442] |
| 总体召回率 | −0.005195 | [−0.023936, +0.015038] |

正式规则要求“实际误报减少至少10%”，同时要求误报率差和Brier差的区间都完全低于0。本轮满足这两项预定改善条件。**不能把它表述为“有95%的置信度保证误报至少减少10%”**：相对减少幅度的区间约为9.70%至26.90%，下端仍低于10%。误报率按“两类误报次数÷歌曲数”计算，折算次数则把每次重抽样的误报率差乘以原始372首，避免重抽样后的歌曲总数变化混淆次数比较。

其他区间只作描述，不代表同时验证了每项指标。氛围单类的Brier变化区间为[−0.012391, +0.001329]，对数损失变化区间为[−0.044443, +0.005833]，都仍跨过0。因此，四类平均概率误差的改善证据更明确，氛围单类概率改善的证据仍不充分。Brier及对数损失反映总体概率预测质量，不等于已经证明每个概率数值都准确校准。

同一艺人可能有带某标签的歌，也有不带该标签的歌，因此两侧艺人数不能直接相加当作总人数。372首下载失败0首、特征提取失败0首。原有控制音频重新提取的特征与缓存完全一致，最大绝对误差为0。

**独立复核已通过。** 主流程完整重放得到逐值完全相同的预测和重抽样结果。独立检查器另外完成144,517项检查，重新构造艺人重抽样、全部指标及判定，复现GO；数值重算的最大绝对差为`1.6653×10⁻¹⁵`。2首下载了完整MP3并验证整文件校验值，其余370首使用受限的音频前缀；前缀和解码音频有各自的校验记录，不能称为370个完整远程文件都经过整文件验证。

**结果能说明到哪里。** 这是固定候选`music-candidate-20260927-v1`与真实v1.1应用的一次新歌比较；两者使用相同MAEST特征、原有上传者标签及每首歌的前30秒。此前开发实验的10.18%属于另一轮结果，本报告的18.42%由这次372首歌曲独立计算。

数据集标签可能不完整，而且标的是整首歌，未必完全描述前30秒。因此这里的“误报”严格来说是“与现有标签不一致”，不能直接断言人耳一定认为模型判断错误。全自动流程保留这个限制，没有让模型自行改写标准答案，也不需要用户试听。

这些歌曲相对于本项目的已有记录是新的，但仍来自同一数据来源。无法保证预训练编码器从未接触过它们，也无法完全识别艺人别名。250位艺人从固定的288位合格艺人中抽取，每位最多两首；这不是对所有音乐平台或所有音乐类型的随机抽样。区间未做有限总体修正，也不包含历史多轮研究、标签遗漏、艺人别名或预训练接触等全部不确定性。

这次结果支持把该固定候选作为下一版应用的依据，后续可以进行版本集成和发布验证。当前应用文件及版本没有被替换。整批候选数据范围已加入[未来排除记录](future_exclusions.json)，不能再作为后续改进的全新考试。
